INPUT VIDEO DAN DATA KURSI

Untuk inference dari video, letakkan video sumber di data/video_part001.mp4
atau ubah source.video_path pada config.yaml. File student_seats.csv yang
disertakan merupakan peta kursi untuk konfigurasi kamera/kelas tertentu.
Untuk ruang atau kamera lain, kalibrasi ulang menggunakan tools/calibrate_seats.py.
